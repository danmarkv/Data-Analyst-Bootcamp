## Topic

COMMON TABLE EXPRESSIONS

## What I did

- CTEs they allow you to define a subquery block that you can reference on the main query.
    - Use WITH to define CTEs.
    - You can only use CTEs immediately after you have created them.
    - You can't reference them anywhere else because they don't create a temp table or permanent object.
- Main purpose of CTEs is to create more advanced calculations that you can't do with just one query.
    - It is also clearner and more readable than using subquery.

## Key takeaway

CTEs are used when doing complex calculations because they make the query cleaner and more readable.
