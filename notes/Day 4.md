## Topic
Data Types and File Types

## What I did
**Data Types**
- A data type is an attribute associated with a piece of data that tells a computer system how to interpret its value.
    - Every Programming Language and Data bases has similar, but slightly different data types.
- Main 3 data types:
    - Strings
    - Numbers
    - Date/Time

**File Types**
- What are File Types?
    - File types refer to the format in which data is stored in a file
    - Each file type is designed for specific purposes, depending on the kind of data it holds and how it will be processed or shared.
    - Think of file types like containers - each designed for a use case.
- File Types:
    - Text files - simple files that store data as plain text, often used for unformatted or tabular data
        - .txt and .csv
    - Structured files - files that store data in a predefined structure, often organized in rows and columns or hierarchical formats
        - .xlsx and .db
    - Semi-structured files - files that have a loose structure, often used to store complex data relationships
        - .json and .xml
    - Unstructured files - files that do not follow a specific format, often containing raw data or multimedia content
        - .png and .mp4
    - Big Data and Specialized files - these file types are designed for handling large-scale data efficiently
        - .parquet


## Key takeaway
- Understanding data types is important because they determine how you process and analyze the data.
- The File Types you choose are extremely important. Choosing the right file type is crucial because it directly impacts how data is stored, shared, analyzed, and used.
