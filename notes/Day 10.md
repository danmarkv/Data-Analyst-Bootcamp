## Topic

ORDER BY

## What I did

- ORDER BY sorts the table based on the column that is specified.
    - ASC for ascending
    - DESC for descending
    - ex. ORDER BY gender, age; or ORDER BY gender, age DESC;
- Take note of the placement of the columns in ORDER BY.
    - ORDER BY age, gender; prioritizes the age and sorts it first before the gender.
- You can also use column position for ORDER BY as a placeholder for the column name.
    - ex. ORDER BY gender, age; = ORDER BY 5, 4; because gender is column 5 while age is column 4.
    - But the best practice is using column names.

## Key takeaway

- ORDER BY sorts the table based on the specified column
