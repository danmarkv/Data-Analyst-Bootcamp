## Topic

LIMIT and ALIASING

## What I did

- LIMIT is specifying how many rows you want in your output.
- LIMIT 2, 1 means from row 2, list 1 row after that
    - so LIMIT 4, 2 is from row 4, count 2 after that
-
- ALIASING is just a way to change the name of the column.
    - ex. SELECT gender, AVG(age) AS avg_age (not necessarily needed to use AS, it can also be a blank)
- Can also be used in JOINS.

## Key takeaway

- LIMIT is for specifying how many rows you want to be outputted and using 2, 1 is skipping 2 rows and returning the next row.
- ALIAS is used for changing column names so that it can be easier to call/use.
