# Day 8 — [Sep 3, 2026]

## Topic

WHERE Clause

## What I did

- WHERE Clause is used to filter records; SELECT is used to filter or select columns
- WHERE Logical Operators - Allow us to have different logic
    - AND - both true
    - OR - at least 1 is true
    - NOT - not true
- PEMDAS also applies to WHERE Clause
- LIKE Statement
    - % - anything
    - \_ - specific value
        - a\_\_ is looking for a + 2 letters/values

## Key takeaway

- WHERE filters specific requirements from the column
- LIKE % looks for a specified sequence
- LIKE \_ looks for the specific number of values/characters
