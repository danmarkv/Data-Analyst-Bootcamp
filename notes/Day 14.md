## Topic

OUTER and SELF JOINS

## What I did

- OUTER JOINS have 2 types: LEFT JOIN and RIGHT JOIN or LEFT OUTER and RIGHT OUTER
    - LEFT is taking everything from the left table, and return the matches from the right table.
    - RIGHT is taking everything from the right table, but if there is no match from the left table, it returns **null.**
- SELF JOIN
    - A join that ties the table to itself.

## Key takeaway

- OUTER LEFT and RIGHT JOINS
    - OUTER LEFT takes everything from the left table and returns the matches from the right table.
    - RIGHT JOINS takes everything from the right table and returns the matches from the left table. If there is no match from the left table, return null.
- SELF JOIN
    - Joining a table by itself.
